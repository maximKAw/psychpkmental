Каталог приложения
«Колледж‑круг» MVP

Сырые данные для мобильного клиента без бэкенда: JSON на GitHub Pages. Приложение читает эти файлы по кнопке «Подтянуть каталог», а пользовательские ответы живут в офлайн-очереди до POST на ваш сервер.

  • Техники (обновляемый каталог)

    Структура: заголовки, короткий подзаголовок, шаги практики. Имена ключей см. в файле.

    techniques.json

  • Советы психолога

    Поддерживающие тексты; сами советы статичные, живые заметки студента добавляются в приложении через очередь.

    psychologist_tips.json

  • Квесты и ежедневные задания

    Тип quest или daily; флажки выполнения и заметки — в SQLite телефона.

    quests.json

  • Правила достижений

    Иконки задаются ключами приложения (air, menu_book и т.д.).

    achievements.json

  • Участники (после Google Forms)

    Roster со стабильным id, именем и email из анкеты; PIN задаётся только в приложении. Обновление — скриптом из таблицы ответов.

    users.json
Если вы открыли эту страницу на Pages, базовый путь задаётся в приложении через GH_PAGES_BASE; для выгрузки ответов — отдельно OUTBOX_INGEST_URL.
